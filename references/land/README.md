# Land references

`driving_test_sop.md` (sample rules: reversing speed, circuit speed, signal, handbrake) and
`basic_theory_notes.md` (guidance) are placeholders for development. Replace them with the
driving centre's test rules and Singapore Basic Theory of Driving / Final Theory of Driving
extracts as `.md` (one `##` heading per section), `.txt`, or `.pdf` (needs `pypdf`). Only `##`
sections are indexed, so this README is ignored.
